# 图仓网站设计

用户已在对话确认：新网站独立账户；Python 后端、SQLite、本地图片存储；注册登录、私有图库、关键词/数量采集、后台进度、去重、下载与删除。

采用 Flask 同源 API 和原生 HTML/CSS/JavaScript，无需前端构建工具。账户密码采用 scrypt；服务端会话仅存令牌摘要，浏览器 HttpOnly Cookie；写请求校验 CSRF；每条查询按账户过滤。图片存放在非公开 data 目录，通过鉴权 API 读取。

每个任务请求 1–200 张图片，同时最多执行 2 个任务，每个账户最多 1 个活动任务。服务重启将活动任务标记为中断。记录已检查数、成功、重复、失败及来源提示；停止后保留已保存图片。单张下载最多 12 MiB，单账户默认配额 500 MiB。仅保存 Pillow 实际识别的栅格图片，按 SHA-256 去重。

百度来源保留原工具缩略图逻辑，修正分页偏移与无条件删项。遇验证码/429 明确失败；可选自动模式在百度被阻止时切换必应公开图片结果，并在任务中标注。必应模式独立可选。拒绝私有、环回、链路本地地址，下载时再次解析验证，并验证每次重定向；不处理 SVG 或任意 HTML。

页面包含登录/注册、采集表单、任务列表、用量统计、可筛选个人图库、图片详情、批量 ZIP 和删除。空状态真实，不预填虚构采集结果。桌面与手机可用。

本机运行在 127.0.0.1:8765；公网运行提供配置与部署说明，须 HTTPS、可信反向代理、持久卷、单进程与多线程。当前不配置第三方网盘或公网主机。
